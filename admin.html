Conecte a loja ao servidor

Sem esta etapa, os produtos que você cadastrar ficam só neste aparelho — nenhum cliente vai vê-los.

  1. Crie um projeto gratuito em console.firebase.google.com
  2. Abra Firestore Database → Criar banco de dados → modo de produção
  3. Na aba Regras, cole o texto que aparece no botão abaixo e publique
  4. Engrenagem → Configurações do projeto → ícone </> → registre o app
  5. Copie o bloco firebaseConfig que aparece e cole aqui embaixo

✅
Conectado! Este aparelho já está publicando no servidor.
📌
Falta um passo para valer em todos os aparelhos.
Abra o arquivo js/produtos.js do seu site, troque o bloco FIREBASE_CONFIG pelo texto abaixo e publique o site de novo.
